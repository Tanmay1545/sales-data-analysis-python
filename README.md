# Sales Data Analysis using Python

## Project Overview
This project analyzes sales transaction data using Python and Pandas to understand revenue, sales performance, product demand, and customer spending patterns.

## Objectives
The goal is to answer common business questions using data analysis and CSV processing.

## Business Questions Answered
- What is the total revenue from all sales?
- How many unique orders were placed?
- What is the total quantity of items sold?
- What is the total revenue generated by each category?
- What is the total revenue generated by each product?
- Which product has the highest quantity sold?
- Which customer spent the most money?
- What is the total revenue for each date?
- What is the total revenue between two given dates?
- How can all Electronics orders be exported into a separate CSV file?

## Technologies Used
- Python
- Pandas
- CSV Data Processing

## Dataset
The dataset contains the following columns:
- OrderID
- Date
- Customer
- Product
- Category
- Quantity
- Price

## Key Analysis
- Overall revenue calculation
- Order and quantity analysis
- Category-wise and product-wise revenue
- Customer spending analysis
- Daily revenue analysis
- Revenue analysis for a selected date range
- Export of Electronics category orders

## How to Run
1. Clone or download this repository.
2. Install the required dependency:
   `pip install -r requirements.txt`
3. Run the script:
   `python sales_analysis.py`

## Output
The script displays the analysis results in the terminal and exports Electronics orders to a separate CSV file.

## Learning Outcomes
- Reading CSV files using Pandas
- Data type conversion and basic data cleaning
- Using `groupby()`, `sum()`, and `nunique()`
- Filtering records using conditions and date ranges
- Exporting filtered data to CSV
